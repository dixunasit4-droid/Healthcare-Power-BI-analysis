Healthcare Data Analysis & Visualization
This project focuses on the cleaning, exploratory data analysis (EDA), and visualization of a comprehensive healthcare dataset. The goal is to uncover trends in patient admissions, medical conditions, and billing patterns to provide actionable insights into hospital operations and patient care.
📊 Project Overview
The dataset contains records of patient admissions, including demographic information, medical conditions, billing amounts, and hospital details. This project demonstrates data preprocessing techniques and the creation of visual dashboards to interpret complex healthcare metrics.

Key Objectives:
Data Cleaning: Handling missing values and normalizing categorical data.

Feature Engineering: Creating new metrics such as Stay_Days and Age Group.

Exploratory Analysis: Identifying correlations between medical conditions and billing.

Visualization: Developing charts to track admission trends by month and demographic.
Column,Description
Name / Age / Gender,Patient demographic details.
Medical Condition,"The primary diagnosis (e.g., Cancer, Diabetes, Obesity)."
Date of Admission,The timestamp for when the patient was admitted.
Billing Amount,The total cost associated with the stay.
Stay_Days,Calculated duration of the hospital stay.
Age Group,"Binned categories for demographic analysis (e.g., 19-35, 36-50)."
Tech Stack
Language: Python

Libraries: Pandas, NumPy, Matplotlib, Seaborn

Environment: Google Colab
💡 Key Insights
Seasonal Trends: Significant peaks in admissions were observed during specific months (e.g., January).

Demographics: The 66+ age group represents a major portion of elective admissions.

Financials: Emergency admissions tend to correlate with higher billing amounts compared to elective stays.
